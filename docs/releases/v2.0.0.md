# Omni AGI Studio v2.0.0

Omni AGI Studio combines local OmniCortex instances, continual learning,
multimodal work and integrations in the existing desktop application.

## Brain state and portability

- Native packed ternary connections include individual integer strengths and
  plasticity state. Packaged workers include the matching packed CPU library.
- Brain Map presents the connected structure as one view, with region and
  pathway inspection, structural identities and recorded activity.
- `.omni` format2 preserves the whole-brain catalog and lineage alongside
  saved neural state, history and artifacts. Older applications cannot read
  format2 exports. Operational keys and device grants remain device-owned.
- Multi-parent merging creates a separate instance, preserves parents and
  retains provenance for shared and distinct state.
- Windows portable workspaces include the application runtime, selected saved
  instance data and settings. Storage reservations are allocated on the
  destination drive rather than shipped as padding.

## Chat, tools and learning

- Chat supports Send, Queue, Steer, Stop, Ponder display, attachments and media
  artifacts, with live progress and compact activity controls.
- Image, audio and video generation use the instance's own modality regions.
  Sensory input and generated artifacts share its learning and provenance flow.
- Specific Learn, constrained web learning and teacher workflows share the
  instance's learning and provenance systems.
- Optional assistants, teachers and reviewers support hosted providers,
  OpenRouter and local Ollama. Provider selection and credentials stay under
  the user's control.
- MCP integrations include typed tools, resources, prompts, interactive
  applications and negotiated durable tasks. Local task history distinguishes
  current-session management from retained history. Stopping a wait preserves
  the remote task; cancelling the remote task is a separate permitted action.
- Custom tools, plugins, automation, scheduling, sandboxes and interactive
  artifacts extend the application through explicit host capabilities.
- Optional map providers include private/offline sources and configured map
  basemaps, with source attribution and provider-specific access settings.

## Packages

| Platform | Package formats | Runtime |
| --- | --- | --- |
| Windows x64 | NSIS, ZIP | x64 application and worker |
| Windows ARM64 | NSIS, ZIP | ARM64 application, x64 worker under Windows emulation |
| macOS Intel/Apple Silicon | DMG, ZIP | Native application and worker |
| Linux x64/ARM64 | AppImage, DEB, tar.gz | Native application and worker |
| Android | Debug-signed APK, unsigned release APK | Desktop-brain companion |
| iOS/iPadOS | Unsigned IPA | Desktop-brain companion |

`RELEASE-MANIFEST.json` records the source commit, package hashes, architectures
and observed signing state. `SHA256SUMS.txt` covers the downloadable artifacts.
Unsigned release artifacts require the platform's applicable installation or
signing steps. The Android debug APK uses a development signature.

Package checks validate the runtime and application shell. Learned fluency,
retention and generated-media quality depend on the instance's training data,
training and supported hardware; package checks do not establish those
capabilities. OmniCortex remains a brain-inspired research architecture and
does not establish consciousness, perfect memory or biological equivalence.
