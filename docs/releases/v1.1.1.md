# Omni AGI Studio v1.1.1

This patch updates the project-owned OmniCortex implementation and application
contracts. It does not include a pretrained model or claim fluent conversation,
perfect memory, consciousness or achieved AGI. Creating/training a native brain
and qualifying its abilities remain separate from this package release.

## Source corrections

- RAM-first packed-core residency, exact tiled attention with designated storage
  backing, and device-derived context capacity instead of a default 32,768 cap.
- Fresh Auto uses the chosen total-RAM envelope for a resident model/context
  baseline with working headroom. Busy apps do not shrink learned geometry;
  pressure or Manual/Extended settings may use storage.
- Fixed RAM-share ceilings with managed-process usage and reclaim-or-pause
  admission. Compression and cold storage remain available; this is not physical
  page pinning or a hard OS-level RSS isolation guarantee.
- Continuous episode-linked temporary activity, incremental neural checkpoints,
  exact scoped weight diagnostics and preserved learned geometry when runtime
  context/RAM/storage settings change.
- Warm safe-boundary steering, durable partial/no-reply receipts, independent
  media cancellation and truthful completed-turn UI state.
- Source-bound streaming ingestion, exact resumable record/window coverage and
  transactional packed distributed updates. Resource pauses never count as
  completed traversal or silently skipped valid records.
- Same-cortex typed action arguments and voluntary action reevaluation during
  composition. Own-voice routing uses the same neural identity; platform STT/TTS
  remain defaults. Useful action choice and intelligible speech need training.
- Packed cortical inspection, scalable sparse state queries and explicit
  observed-activity coverage rather than relabeling confidence as firing.
- Protected recursive source/compatible-architecture candidates with immutable
  evaluation/origin boundaries, lineage and rollback. This is not evidence that
  autonomous candidates improve intelligence.
- Unsanitized saved-instance exports, recovery references and inert historical
  tool intents. Treat exports as private backups: saved content can contain
  sensitive data. External credential vaults are excluded; imports do not replay
  ancestral approvals or automatically resume relocated external datasets.

## Automatic video runtime

The independent [video runtime release](https://github.com/Eabusham2/Omni-AGI/releases/tag/omni-video-9.0.2-r1)
provides hash-pinned Windows, macOS and Linux x64/ARM64 executables with matching
FFmpeg/x264 sources, build material and GPL notices. All six targets passed real
H.264/AAC encode/decode checks; all 43 uploaded hashes were verified. First use
has owned, cancellable setup without replacing the occupied neural worker.
This does not prove the quality of AI-generated video or provide patent clearance.

## Package verification and limits

Publication is gated by source/UI-contract checks, packaged-worker health and
desktop/mobile package verification. No native brain is created or trained by
those package jobs. Mobile emulator checks exercise the gateway protocol with
a fixture server, not a broadly trained brain.

Windows ARM64 uses a native desktop shell with an explicitly labeled emulated
x64 neural worker. Signing/notarization is enabled only when credentials are
configured; otherwise artifacts are labeled unsigned and signing-ready. The
unsigned mobile release packages require signing before normal installation.

See [implementation status](https://github.com/Eabusham2/Omni-AGI/blob/v1.1.1/docs/IMPLEMENTATION_STATUS.md) for current boundaries
and deferred trained-native qualification. The release manifest and checksums
bind the published packages to the tagged source commit.
