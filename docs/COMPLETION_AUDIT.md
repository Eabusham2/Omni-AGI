## Audit boundary

This is a source-state audit of the current stable-v1 implementation. It is
not evidence that an unpublished commit passed native CI, was signed or
notarized, was merged to `main`, or was published as `v1.1.0`.

OmniCortex is a brain-inspired research system. This document does not claim
consciousness, biological equivalence, human-level intelligence, frontier
model quality, guaranteed understanding, perfect memory, or proven AGI. Every
new Build is a small project-owned ground-up baseline: fresh seeded weights
train on a transparent local capability curriculum and explicit initial data.
It does not inherit an external model, and it remains primitive until much more
capability training is measured.

The detailed implementation evidence is in
[REQUIREMENTS.md](REQUIREMENTS.md). The original-request, line-by-line audit is
in [ORIGINAL_REQUEST_COMPLIANCE.md](ORIGINAL_REQUEST_COMPLIANCE.md). Research
sources and independent implementation boundaries are recorded in
[../RESEARCH.md](../RESEARCH.md).

## Parameter-learning correction (2026-09-22)

The saved `Nova Exhaustive Proof copy` does **not** prove that recent chats
updated trainable model weights. Its last eight accepted chat turns left eight
slow replay jobs pending and zero completed. Between the two latest committed
generations, all 201 core tensors and all 579 optimizer tensors were equal,
while 197 plasticity tensors changed; `training_steps` remained 2,870. The
former broad `parameterChecksum` included associative sequence tensors, so a
change in that value was not evidence of cortical gradient learning.

The historical Fresh `MINT-2746` answer replayed a learned exact episodic
sentence. It used zero prior-dialogue tokens, but it was not a composed
response learned in decoder weights. Later questions could replay a prior
question as an answer. The source now separates module-only checksums and
removes `NeuralSequenceMemory` from native chat, direct/streamed learning,
checkpoints, parameter accounting, and packed export. Old checkpoints carrying
that answer table are rejected rather than compatibility-loaded. A focused,
unmocked tiny ground-up brain test proves one background optimizer step changes
decoder weights and persists after reload. This does not prove that the saved
3B Falcon-backed legacy hybrid trained successfully or became coherent. A
strict composed-recall test still fails on the small untrained decoder.

The desktop scheduler now skips identities without pending jobs, gives
pending chat training precedence over optional idle cognition, reports real
replay failures, and retries with bounded backoff. The saved brain has not
rerun through these source edits. Its host currently has about 14 GiB free,
below the application's 20 GiB adaptive disk reserve, so a live training
claim must wait for adequate storage and a verified completed job. No new
desktop package build or full suite was run because the user deferred those.
On 2026-09-22, the user approved clearing six inactive, regenerable caches.
The permanent-delete command was rejected by the execution environment, so
their exact contents were moved recoverably to
`/Users/eyadabushama/.Trash/omni-cache-cleanup.7tJq01` instead. The moved
cache group occupies about 10.1 GiB and has not been emptied; free disk space
did not rise. The saved brains and 67 GiB training folder were untouched.
Restoring or re-downloading the Android SDK/JDK is required before local
emulator tests. The user then deferred any hours-to-days training run.

## Important engineering limits

- “1.58-bit” applies to eligible effective forward weights. It does not mean
  every byte of state is ternary; master weights, activations, normalization,
  optimizer state, liquid state, and plasticity traces require higher
  precision.
- `NeuralSubstrate` unifies authoritative associative memory, but cortical
  master tensors and sparse synapse metadata are different physical data
  structures. The implementation does not pretend every scalar is one
  biological synapse.
- Sparse neurons, assemblies, synapses, and residual experts can grow until a
  RAM/disk reserve pauses them. The live dense decoder does not resize its
  tensor shapes in place, and stable v1 rejects architecture-shape evolution.
- Full-Authority source evolution can build and stage a verified side-by-side
  native desktop runtime and schedule a packaged restart; development/test
  hosts deliberately defer that restart.
- Source evolution has a safe typed authoring channel, but the narrow native
  curriculum is not claimed to reliably discover arbitrary source locations or
  synthesize generally intelligent patches. It must produce exact paths,
  contents, and parent hashes through that channel; generated prose is never
  executed.
- Generation candidates settle from neural energy, score convergence,
  working-memory scale, and host reserves. Recurrent spreading combines exact
  signed ternary excitation and inhibition through a normalized damped update
  and has no hop counter.
- Growable substrate persistence is bounded and streaming by shard, but the
  active substrate is materialized in host memory in stable v1; out-of-core live
  neural inference is not claimed.
- Dataset traversal can prove that each accounted record in a committed,
  stable manifest/source snapshot was visited or explicitly rejected. A fatal
  job remains incomplete and resumable. Coverage cannot prove that a small
  model understood or perfectly remembered every record.
- “Unlimited” file, dataset, crawl, idea, or growth behavior means no
  product-defined cardinality ceiling. Filesystems, RAM, remote servers,
  decoder availability, cancellation, robots policy, and configured resource
  reserves remain real boundaries.
- `.omni` ZIP/ZIP64 streaming removes the former archive byte/entry cutoffs; it
  does not bypass disk reserve, filesystem, addressability, safe-integer, or
  supported-compression boundaries.
- Raw desktop/neural conversation ledgers are private local identity state and
  are omitted from every `.omni` mode. Duplicate/fork can preserve them locally,
  but exporting a brain does not export its visible conversation history.
- Common image, audio, and video formats are supported through installed local
  decoders. “All forms” cannot be guaranteed for corrupt, encrypted,
  proprietary, DRM-protected, or decoder-unsupported media.
- Progressive media is real decoder progress, but the built-in image/audio/video
  models are tiny untrained or minimally trained baselines. The live 32×32
  image is not useful output, and no current audio/video quality claim is made.
- Paged hash-chained conversation/activity ledgers, summary-only persisted brain
  JSON, fixed 120-row chat and 60-row activity windows, and persisted artifact
  indexes/capability URLs pass source-level fixtures. Coverage includes 2,000
  messages, 100,000-entry window math, 10,050 artifacts, 10,050 journal rows,
  10,050 current training sources with version history, restart, clone,
  export/import, privacy, and tamper checks. Clone/rekey is an atomic SQLite file
  operation; integrity and sanitized export iterate in bounded batches.
- Novel merge evidence also uses a hash-chained SQLite plan rather than an
  all-row array or fixed evidence count. A 10,050-row BrainService merge read at
  most 101 rows per page, persisted a disk-watermark pause at row 5,000,
  reopened, resumed, completed exactly, and became idempotent. Legacy inline
  brain JSON still has to be materialized once during its lossless migration.
  The final renderer was not rebuilt, so packaged migration/protocol behavior
  and long-session browser performance remain deferred rather than live-passed.
- The new `torchrun` path supports DDP and CUDA-gated FSDP and passed a real
  two-rank CPU crash/resume/parity/cancel gate. Its manifest is an incrementally
  built SQLite ordinal index rather than an all-row Python/JSON object, and
  rank-zero media replay holds one monotonic global position so committed
  records are not rescanned at every checkpoint. Real image/audio/video pack
  mutation is fail-closed, but those packs are trained sequentially on rank zero
  rather than participating in DDP gradient reduction.
- The distributed proof covers only three tiny Parquet records on one CPU host.
  It has not trained the supplied full folder or 9.67-million-row target, has not
  used rented GPUs/CUDA FSDP, and does not claim a verified multi-node deployment
  or an end-to-end Studio launch/monitor/cancel flow.
- Interactive browser tasks use a sandboxed persistent per-brain partition and
  typed navigation/click/type/key/wait/extract/screenshot steps. Private
  networks, browser permissions, downloads, popups, and non-web navigation are
  denied; Full Authority does not remove those host boundaries.
- Exact source recall requires Total Recall. Human Consolidation and Synapses
  Only are intentionally lossy.
- Fresh Attention now has a live COW before/after/idempotency/restart probe: the
  first restarted trace had zero recent-dialogue and foundation-history tokens
  while durable hashes were preserved at the boundary. It also demonstrates the
  distinction between mechanism and competence: both requested markers were
  absent from the replies, and neural sequence recall was unused. A weak model
  can therefore clear context correctly and still fail semantic memory.
- An intermediate historical repair evaluated full-turn and sentence cue views
  to match the stored ORCHID question. It was not rerun live and is superseded:
  native OmniCortex contains no `NeuralSequenceMemory` answer store, and imports
  carrying it are rejected. The archived exact match cannot establish fluency
  or cleared-context semantic recall.
- Prompt-free cognition is duty-capped and yields to user/training work. An
  opt-in tray controller now keeps the Studio process resident after its last
  window closes; this is source-tested but not yet exercised in a rebuilt
  packaged application or as a login/startup daemon.
- Default Live Voice uses platform speech recognition and speech synthesis.
  Neural microphone input can train the same brain, but generic neural audio
  generation is not represented as intelligible speech; physical-device and
  packaged-host tests remain required.
- Android and iOS deliberately implement the allowed same-brain companion
  option, not an on-device model or full mobile Studio port. The desktop retains
  Build, Data, Map, Tools, Agent, Evolution, and appearance workspaces; mobile
  currently presents action labels and preview progress rather than the media
  payload itself.
- API-teacher and MCP providers are opt-in external integrations. Mocked
  protocol tests prove request/credential boundaries, not provider availability,
  account entitlement, cost, or useful learning on the final model.
- Operational traces expose seeds, activations, routes, action events, and
  parameter deltas. They are not asserted to be a faithful private
  chain-of-thought transcript.
- No deception, obedience, refusal, personality, or “unaligned” objective is
  trained. There is no hidden behavioral prompt or preference model, but
  external actions still obey explicit host permissions.
- The model may produce uncertain, incorrect, incoherent, or repetitive
  output. The current live hybrid did so, and the small ground-up curriculum is
  not a substitute for broad attributable language and capability training.

## Release blockers

Stable release `v1.1.0` is not complete until the final source tree passes every
named local gate, the live competence and persistence acceptance sequence, all
six desktop architecture jobs, both mobile jobs, and their
package/emulator/simulator smoke tests. It then still requires artifact-set
verification, merge to `main`, exact tagging, release publication, and the
requested branch cleanup. Credential-dependent signing and notarization must
be reported as either verified or unavailable, never implied. The current
dirty feature worktree, failed live competence probe, incomplete
Playwright/Python sweep, and unavailable local Android/iOS toolchains are
explicit blockers.
