# Memory acceptance: native model generation without an answer table

The product gate is generated recall from a trained OmniCortex after transient
context is cleared and the worker restarts. An exact match from a separate
cue-to-sequence table is not a pass. Native OmniCortex no longer includes
`NeuralSequenceMemory` in chat, learning, checkpoints, parameter accounting, or
packed export. Old checkpoints containing that state are rejected by
whole-brain Import rather than opened for compatibility. Historical diagnostic
receipts may remain as research records, but they are not a product brain.

## Overlapping mechanisms

An accepted textual experience can update these overlapping mechanisms when
its source policy and resource envelope admit them. This is not a fixed-stage
conveyor, and no rule permanently classifies an experience as a fact:

- semantic substrate learning alongside working/replay activity;
- a lossy shared statistical semantic field keyed by attributed source and kind,
  not by question-to-answer cues;
- local spiking/STDP and sparse-assembly synaptic mutation;
- slow parameter learning when enabled and resource-admitted.

Generation may use the bounded recent human/brain token ring as truthful
working context. Queued slow replay may later read the saved human message as
attributable training evidence. Neither mechanism retrieves historical source
text into a new generation prompt, and neither by itself proves cleared-context
semantic recall.

An archived old sequence diagnostic may have reconstructed exact content. Its
score or reconstruction was never evidence that the answering cortex learned
to generate that content. Historical receipts may retain those counters only
as evidence explaining why old acceptance claims were invalid.

## Per-path matrix

| Path | Authoritative route | Exact no-context acceptance | Semantic acceptance |
| --- | --- | --- | --- |
| Ordinary messy chat experience | User text admitted by `chat`; generated text is not treated as truth | Not applicable: no sequence lookup or chat-specific answer-key write | Prove fast synapse changes, queued and completed slow cortical updates, then held-out generated behavior after Fresh/restart |
| Direct `learn_experience` | Direct attributed text experience through native substrate/cortical learning | Not applicable: no sequence answer-key policy exists in the native path | Substrate and cortical change require separate evidence; no lookup score counts as generation |
| Typed JSONL | `messages` row parsed as `typed-dialogue` | Not applicable; declared targets supervise the mutable cortex without creating sequence answer entries | Prove records visited, optimizer changes, and held-out generated behavior |
| Plain file and Parquet row | Complete accepted text record | Not applicable by default | Prove full traversal, neural mutations, and generated recall without source injection |
| Web crawl | Non-quarantined accepted text after HTML-to-text normalization | Not applicable by default | Prove frontier/coverage, neural mutations, and generated recall; quarantine remains provenance only |

No product path is selected by patterns such as “the code is,” “remember this
fact,” or a capitalized token. Typed dataset boundaries are training labels,
not a fact detector or an assistant answer table.

## No-context model proof

For a product-level chat-learning claim, clear prior attention/context,
restart the worker, then require:

- zero prior recent-dialogue tokens;
- zero foundation-history messages;
- no prior prompt-text expansion;
- no raw source-text injection or retrieval;
- an attributable, accepted source and complete manifest/crawl coverage where
  the source is streamed;
- fast synaptic mutation plus a completed, module-only cortical weight update
  that survives reload; and
- a correct, nonverbatim response generated from model logits to a held-out
  question that does not contain the answer.

An archived old-checkpoint sequence diagnostic may report similarity, margin,
and reconstructed text, but the current importer does not load that backend and
the record cannot prove the product gate. Chat fluency and cleared-context
recall have **not** been established for a current native saved brain.

## Implemented integration contract

Historical results remain documentation only. Native fixtures guard the absence
of cue-to-answer tensors and verify fast and slow weight changes in tiny
ground-up cases. The strict generated-answer gates remain separate and
currently unproved. A successful focused fixture cannot replace a complete,
live, ground-up trained-brain run.
