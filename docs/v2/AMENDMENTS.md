## Implementation contract

One plastic native brain, overlapping specialization and real recurrent/shared
connections remain the target. The main map must compose the actual whole
structure, with multiresolution inspection and the same underlying identities.
Region detail is a drill-down, not a claim of separate brains. Structural
connectivity, source-time observations and learned parameter/contact values
must remain distinguishable. An unavailable mapping is not license to draw a
plausible but unrecorded link. Human-inspired properties do not by themselves
prove biological equivalence, intelligence or consciousness.

The existing separate domain tabs are a confirmed UI gap against this latest
request. A source catalog, unified projection, typed application bridge and
bounded visual checks are required; merely renaming the router view does not
fulfill the request. New brain training remains deferred as previously decided.

to original host paths, unrelated history, staged/unsent files, another task,
