# Within-turn sensory handoff

October20 source/focused-contract record for the independently found R190/F3
connection gap. No brain was created, loaded, trained or quizzed for this work.

## Actual owner, not a second neural writer

Main sends live-session controls and packets to the exact existing reply
worker through `requestLiveObservation`. The ordinary serialized path remains
for an idle, already-loaded session. Capture transport does not acquire the
Stop/shutdown reserve or silently replace the generation worker. The stdin
reader validates and retains immutable, normally admitted bytes; it does not
encode a frame or mutate neural state. Brain, turn/request, session, capture
revision, permission binding, sequence/timestamp and actual byte checksum are
checked at their real consumption boundary.

`LiveSensoryInbox` retains each ordinary RPC allocation until integration or
rejection. Enqueue is not an acknowledgement of use. The actual world owner
drains it at a safe neural boundary, encodes through the same brain and returns
the new native conditioning vector with exact sensory bindings. These are not
tool IDs, retrieved prose, a prompt injection, canned answers or a Q/A store.

Canonical Ponder admits input between passes and refreshes its canonical
membrane/spike baseline so scratch restoration cannot undo admitted sensory
activity. Best Work admits at the scheduler boundary outside private candidate
advances. Private candidates and calibration do not consume the inbox. Pending
bindings reach selected real decoding and survive the actual native cursor's
Unload/resume boundary without re-consuming frames or serializing callbacks.

## Normal memory and honest failure custody

Active-turn observations bind the actual admitted episode. An eligible idle
session admits one real observed episode and reuses the existing working,
afterimage, settling and replay paths. There is no forced per-frame optimizer,
new fixed learning timer or shortcut that immediately stores every input as a
permanent answer. Explicit working-only input remains transient. Mounted Call
already requested neural retention; its default was not changed. The separate
raw-audio transient path is retained.

Stop retires queued session input before waiting for pending packets. Turn,
Steer, Unload and session retirement reject/release their owned pending input.
Pending provenance has its own admitted metadata allocation.

Pre-integration refusal is reported as not started. A later exception may have
already changed packed/working state, so it reports effects unknown with no
automatic retry, retires the inbox and aborts the turn. Ordinary failed-chat
recovery owns restoration. Inherited views borrow shared regional owners;
their actual root is fenced before error delivery, and existing save/load
checks prevent publishing that dirty root until verified recovery. No rollback
or remote cancellation is invented. Rejection-delivery failure still releases
the retained leases. Already-dequeued tool-result leases are released even if
sensory conditioning fails before those results are integrated.

## Bounded evidence

- Fifteen constructor-free Python cases passed under `NoNeuralImports`; one
  subsequently added release-finally case separately passed. These are sixteen
  distinct cases, not a claim of a fresh combined sixteen-case run.
- Three new inert EngineSupervisor cases passed; ten affected backend fixture
  cases, one new stale-controller-revision case and one exact selector/list
  case passed. Fixture ownership/context declarations were corrected without
  weakening production types or worker checks.
- Independent source review found and then cleared the canonical Ponder/search,
  partial-effect, inherited-root and suspended-provenance defects.
- Coordinated Node/Web TypeScript checks and shell-only bundling passed. The
  initial Node check found three incomplete inert context declarations; their
  required owner/request/label fields were corrected and Node passed afterward.

These checks establish source handoff, custody and bounded failure behavior.
They do not prove live camera/microphone behavior, learned comprehension,
neural quality, real-time performance, all-theme UI, packages or final release.
Full new-brain/full-folder quality qualification remains explicitly deferred.
