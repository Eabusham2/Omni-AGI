# Fixed memory owners in aggregate placement

This extends the current thirteen complete-operation consumers. It does not add
a fourteenth work kind, create/load a brain, change the learned memory algorithm,
or claim whole-reply optimization or measured speedup.

## Actual runtime composition

`whole_path_scheduler.py` is composed at the real serialized `Worker.dispatch`
request boundary, after its existing device/resource preparation. The request
owns its runtime-only scope and receipt hash. Metadata/status/inspection polls
do not start a scope or write an event. Nested, unarmed, changed-owner and later
requests cannot inherit a preceding request's prefix authority.

Actual existing memory entries annotate their own genuine execution:

- experience learning, including substrate assembly admission, liquid activity,
  STDP, connected observations, optional slow learning and real resource upkeep;
- replay and working-memory admission;
- continuous organic settling and recent-dialogue admission/decay;
- the current-memory chat preview;
- sensory experience admission;
- actual root/connected router LIF/STDP and feedback, and connected regional
  experience observation.

Those bodies run once on their original owners. Nested phase times are visible
but are not added twice to the aggregate duration. Existing owned resources are
reclaimed at their original safe boundary before a measured mutation, subject
to the same selected RAM, storage opt-in and physical disk policy. Prior async
work is drained separately; the real body/preflight and home completion form
the fixed duration. Request elapsed time additionally includes bookkeeping and
comparison overhead. A sampled resource peak is not an exact allocator maximum.

The mutable graph/SQLite, transient workspace, recurrent state, replay and STDP
closure cannot currently be privately migrated as one atomic object. It stays
on its actual CPU/home owner. No before-image rollback is presented as private
learning, and no memory body, DB write, graph growth, source/cursor admission,
tool effect or real learning callback is repeated to compare placements.
Private operation trials are explicitly refused before entering an annotated
lasting-memory/STDP body. Normal ordinary processing and the existing gradual
memory lifecycle remain in place.

## Actual selection and resources

All six existing policy/controller implementations, covering the thirteen work
kinds, invoke the common complete-operation selector seam. If this request has
completed fixed memory work, `NativeFixedMemoryOps` checks the current owner/
session, policy object/hash, selected device budgets, topology review, context
capacity/occupancy, slow-storage opt-in and operational memory frontier. The
frontier is an owner/cursor fence, not a serialized inventory of facts or a
copied brain. Connected owner traversal streams a hash and admits metadata by
actual nesting depth; shared borrowed regions are not mistaken for cycles or
flattened into one call.

The scheduler authenticates each original complete-operation receipt and its
existing native evidence custody. It forms a conditional aggregate from the
**one already observed fixed memory prefix plus matched complete-compute
samples**. The ordinary candidate remains available. Only the existing exact
output/state gates and admitted whole-operation samples can select another
compute target. There are no primitive projection timings, link-bandwidth
guesses or previous-request memory receipts authorizing placement.

Costs include the transfers actually performed by the fixed memory body and by
the complete compute consumer. Sequential resource peaks combine by physical
group using their maximum; they are not summed as RAM plus Metal capacity.
The common native resource sampler observes every real target/home participant.
A distinct home GPU remains included while it owns memory and receives outputs;
unrelated GPUs remain excluded. Multiple non-RAM allocator views with one
ambiguous physical-group identity cannot authorize a route without a proven
physical usage counter.

Changed or unproven ownership, disabled allocations, changed capacities,
pressure, incomplete stages, stale context, a stopped policy, missing samples
or altered receipt custody retain the current ordinary candidate. No selector
is rerun over a partially consumed iterator. Metadata or diagnostic failure
cannot replay or turn a committed real learning body into a failed update.
The existing request's cancellation and transactions retain their semantics;
Stop Auto retires comparison authority rather than undoing a genuine update.

Private derived rows are serialized under explicit metadata admission, streamed
and released. The native selection journal records the aggregate basis, fixed
duration, source comparison and fixed-owner choice. The final source-free
request summary records real phase counts/hash, duration, status and metadata
issues. Neither imported event JSON nor a public checksum recreates the live
request, private issued receipt stream, controller or permission.

## Verification boundary

Twelve distinct NEW cases in `test_whole_path_memory_scheduler.py` pass across
affected selections. The initial eight passed191ms. Two new production-adapter/
request-polling cases passed with two affected memory/failure cases in11ms.
The shared-parent/depth-admission case passed below1ms. The actual resource
sampler's target/home/shared-group case passed8ms. Later affected selections
checked finalized reclamation, stream custody and source annotations. Fixtures
use inert metadata, fake sampled budgets/clocks, tiny real SQLite writes and
AST-extracted source functions. They prove their stated source, receipt,
ownership and once-only effect boundaries; their times are not hardware speed
measurements. Changed sources compile. Closed operation, native forward, host,
training, model and hardware suites were not rerun.

## Remaining implementation versus missing evidence

Implemented here: the real request seam, fixed-owner memory/STDP processing and
admission, complete-operation selector consumption of its actual prefix costs,
current-owner/resource/context fences, source custody, nonduplicated learning
effects and all-participant resource observation. Useful memory still follows
the existing activation, reuse, interference, salience, stability and decay
logic; no new fact lookup or eager permanent-store rule was added.

The ordinary actual reply-level planner/consumer is now implemented across
`AdaptiveBrain.chat` and `OmniDecoder._generate_scoped_iter`; see
[reply-execution-planner.md](reply-execution-planner.md). Its real stage
dispatch, complete-consumer choice, current Event custody and once-only
callbacks are separate from the earlier summary. A global privately replayed
conversation and whole-reply speedup are not claimed. Actual complete-reply
hardware/learned behavior is still unverified.

Subsequent source slices are now implemented:

1. Qualified mixed **sequential** decoder-region candidates inside the six
   ordinary/connected cached, prefix and full-forward text kinds. They retain
   exact complete-operation gates and actual participant resources; other kinds
   do not acquire mixed support. See mixed-region-complete-operations.md.
2. Outer modality/replay/evolution owner-phase orchestration and once-only
   checkpoint/cursor publication. Actual prepared-wave execution consumes its
   current admitted selection; mutable outer phases stay on their real owners,
   not a privately relocated whole pipeline. See outer-learning-pipeline.md.

Remaining R1 implementation breadth is concurrent multi-device/cross-rank
execution and collective custody, retained GPU cache/context subtree migration,
unsupported direct accelerator kernels, and mixed consumers beyond those six
text kinds where supported. A local complete-operation sample does not
authorize distributed training or a globally optimal schedule.

Missing evidence, rather than automatically another code gap: real native
memory/learning quality, actual accelerator/drive/transfer performance, complete
hardware latency/pressure comparisons, large-state throughput and packaged
platform behavior. No model construction, Load, neural forward/backward,
training, actual GPU or benchmark ran. The user-deferred full training and
merged-resume learned proof remain deferred.
