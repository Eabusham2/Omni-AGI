## Genuine publication path

The existing learned argument head may emit `{emit,text?}` only after actual
voluntary recurrent Ponder. No new model, canned explanation, behavioral prompt
or hidden chain-of-thought is introduced. The complete neural report is decoded
before action-first bounded UTF-8 publication begins. Native/main validate
identity, ordering, byte coverage and final checksum. Accepted partial text
survives Stop/failure/detachment without an invented final hash or remainder.

`PonderPresentationLedger` consumes only typed publication frames for a known
same-turn Ponder action. The worker's32-hex action identity joins
`ActionEvent.neuralActionId`; the host event UUID is separate. The initial
renderer incorrectly joined those different identities; this was fixed and the
affected cases now use distinct IDs. A `publishing` announcement without text
is not displayed as prose or rejected as a false invalid-prefix error.

`reconcilePonderPresentation` restores partial custody from saved action
arguments and complete message reports. Longer accepted compatible prefixes
are not silently truncated. Conflicting/invalid saved publications are surfaced.
Settled live copies retire only after exact saved message/action custody exists;
this frees derived renderer memory without dropping uncommitted prefixes or
deleting any history. Completed action publication alone does not fast-forward
the active readable display; terminal/hidden/committed reply boundaries do.
The main action fingerprint excludes report text; no duplicate action is made.
Report JSON is omitted from the ordinary action-arguments snippet and shown as
readable text inside the Ponder action. When its action is outside the current
history window, message-bound text retains a compact Ponder disclosure.

`PonderSelfReportView` has a default-off Readable speed button. It limits only
visible Unicode code points, not inference, reception or other reply tokens.
Terminal/hidden views show every accepted byte immediately; unmount removes
animation frames and does not claim neural cancellation. Silent Ponder remains
silent. Model-emitted prose is a self-report, not verified private thought.
