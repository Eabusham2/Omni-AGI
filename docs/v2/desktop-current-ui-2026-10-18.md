## Boundary

These are actual native-renderer interactions and two observed appearance/
ordering corrections. They do not establish runtime IPC, full corpus coverage,
learning, current hardware fit, backend transitions, a complete theme/layout/
accessibility matrix or packaged Windows/macOS/Linux behavior. The broader U1
and service/platform gates remain separate. No existing successful test was
rerun merely to increase a count; CSS/copy changes were checked in the affected
visible states rather than receiving mirror string tests.
